# Homework 5 — FastQC, MultiQC and trimming

This folder contains the report and supplementary files for homework 5.

## Contents

- `HW5_report.ipynb` — main report
- `scripts/` — SLURM scripts for FastQC, MultiQC and trimming
- `results/` — FastQC/MultiQC reports before and after trimming
- `screenshots/` — screenshots used in the report
- `data_files_used.txt` — list of input files used in the analysis, if available

## Main tasks

1. Quality control of raw sequencing reads using FastQC and MultiQC.
2. Read trimming using fastp or Trimmomatic.
3. Quality control after trimming and comparison of metrics before and after trimming.

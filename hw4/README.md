# Homework 4 — Genome assembly

This folder contains the report and supplementary files for homework 4.

## Contents

- `HW4_report.ipynb` — main report
- `scripts/` — SLURM and shell scripts used for Velvet, SPAdes and QUAST
- `quast_reports/` — QUAST reports for initial and improved assemblies
- `screenshots/` — screenshots used in the report
- `source_results/` — assembly outputs and additional source files

## Main tasks

1. Genome assembly with Velvet using several k-mer values.
2. Comparison of Velvet and SPAdes assemblies using QUAST.
3. Improved assemblies with modified parameters and final comparison.
